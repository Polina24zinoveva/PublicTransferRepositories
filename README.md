Приложение предназначено для переноса репозиториев из облачного хранилища GitLab в GitHub через сохранение на локальном диске. 

Для работы небходимо в файле application.uml вставить свои данные для GitLab (token, url, urlUser, idUser), GitHub (token, url, urlUser, userName), а также создать в проекте папку localRepositoriesдля хранения репозиториев на локальном диске и указать путь к ней (localRepositoriesPath).
